# 월별 매출 집계하기

[공통 작업 기준](../principles/#common)을 먼저 복사한 뒤 아래 순서로 진행하세요.

## 1단계: 데이터 구조 점검 및 무결성 검증 (EDA)

```prompt
[역할]
너는 15년 차 데이터 분석가 및 엑셀 수석 데이터 엔지니어이다.

[작업 범위]
첨부된 데이터셋의 결측치, 이상치, 데이터 타입을 검증하고 무결성 리포트를 작성해라.

[수행 단계]

행·열 수, 컬럼별 데이터 타입, 기초통계, 결측 건수를 확인해라.
중복 데이터(Duplicate Rows) 수 및 컬럼별 데이터 타입 일치 여부를 파악해라.
데이터 이상치(Outlier)를 IQR 기준으로 검출해라.

[출력 형식]

데이터 개요 (행/열 개수, 메모리 사용량)
결측치 및 조치 제안 (컬럼명 | 결측 수 | 비율 | 권장 조치방안)
이상치 검출 결과 요약
```

## 2단계: 다차원 피벗 분석 및 통계 지표 산출

```prompt sales-analysis
[작업 목표]
제공된 매출 데이터셋을 기반으로 핵심 경영 지표 분석 및 다차원 피벗 테이블을 생성해라.

[분석 요구사항]
1. 월별 / 제품군별 / 지역별 매출합계 및 비중(%)을 계산해라.
2. 전월 대비 성장률(MoM), 전년 동기 대비 성장률(YoY)을 산출해라.
3. 평균 주문금액(AOV)은 집계 대상 매출 ÷ 고유 주문 수로 산출해라. 고객당 매출은 같은 매출 ÷ 고유 구매 고객 수로 별도 표시해라. 취소·환불 처리 기준을 명시하고, 필요한 식별자가 없으면 해당 지표에 [확인 필요]를 표시해라. 고객별 매출을 내림차순으로 정렬해 상위 20% 고객의 매출 비중도 구해라.

[출력 요구사항]
- 모든 통계 수치는 소수점 둘째 자리에서 반올림할 것.
- 계산식과 집계 기준을 제시하고, 반복 실행이 필요하면 재현용 코드도 제공할 것.
- 아래 양식으로 개조식 요약 결과를 작성할 것.

[요약 양식]
- 주요 성과: 
- 위험 요인: 
- 개선 제안:
```

## 3단계: 가공 데이터 다운로드용 서식 적용 엑셀(.xlsx) 파일 생성

```prompt
[목표]
수정된 데이터를 전문적인 스타일이 적용된 .xlsx 파일로 생성하여 다운로드 링크를 제공해라.

[서식 규칙]

Header Row: 배경색 #1E3A8A (Dark Blue), 글자색 #FFFFFF, Bold 처리, 높이 25pt.
Data Row: 높이 20pt, 테두리(Border) 얇은 실선(#CBD5E1), 천 단위 콤마(,) 적용.
수식 보존: 단순 값이 아닌 엑셀 수식(SUM, AVERAGE, IF 등)을 그대로 반영할 것.
열 너비(Auto-fit): 데이터 길이에 맞춰 컬럼 너비를 자동으로 조절할 것.

[실행 코드 요구]
집계 기준을 적용한 원자료 합계와 최종 보고서 총계를 대조하고 대표 수식의 참조 범위와 계산 결과를 확인한 뒤 .xlsx 파일을 제공해라.
```

## 💡 엑셀 실무 팁

계산 검증: 원자료에 동일한 취소·환불 기준을 적용한 합계와 보고서 총계를 대조하고 차이가 있으면 원인을 기록합니다.

통계 기준 명시: 평균값(Mean)과 중앙값(Median) 중 어떤 것을 쓸 것인지, 결측치 처리 방식(삭제 vs 대체)을 사전에 지정합니다.

엑셀 수식 보존: 파이썬으로 처리 후 엑셀에 적재할 때 단순 텍스트/숫자가 아닌 `=SUM(C2:C10)`과 같은 실제 수식을 삽입하도록 지시합니다.
