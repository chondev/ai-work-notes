# 업무에 맞는 요청문 쓰기

## 요청 한 줄을 업무 지시로 바꾸기

‘메일 써줘’에 세 가지를 더하면 초안의 방향이 정해진다. 누가 읽는지, 읽고 무엇을 해야 하는지, 어떤 사실을 근거로 쓸지 적는다. 분량과 말투는 결과를 쓸 곳에 맞춘다.

기본 양식

```prompt
[받는 사람]이 [다음 행동]을 할 수 있도록 [자료]를 바탕으로 [결과물]을 작성해줘. 반드시 포함할 내용은 [핵심 사실]이고, [분량·말투]로 써줘. 자료에 없는 날짜·담당자·약속은 [확인 필요]로 남겨줘.
```

예를 들어 ‘회의 내용 정리해줘’에 ‘불참한 팀원이 내일 할 일을 알 수 있게’라고 덧붙이면, 발언 순서보다 결정 사항과 후속 조치가 먼저 나온다. 아래 예시는 각각 단독으로 복사해 쓸 수 있다.

## 초안이 빗나갔을 때

처음부터 다시 요청하기 전에 유지할 부분과 바꿀 부분을 짚어준다.

```prompt
견적 요청 사유와 기한은 그대로 두고, 상대에게 책임을 묻는 표현만 중립적으로 바꿔줘. 제목과 본문 전체를 다시 보여줘.
```
